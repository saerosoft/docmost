Library and host integration

The built ES module is dist/note-gui.js, with declarations under dist/types/; the separate stylesheet is dist/note-gui.css. A browser host loads the CSS and imports the module, calls mountNoteGui with its container, and calls the returned unmount during cleanup. Serve the complete distribution, including generated chunks, local fonts and this source offer. The package is private and consumed from its pinned public repository; no npm publication is claimed.

Build

pnpm install --frozen-lockfile
pnpm test
pnpm source
pnpm build

Use Node.js 26, pnpm 10.29.2 and Python 3.12 or later. See README.md in the archive for library exports, CSS loading, host cleanup, API routing and source-distribution requirements. Third-party packages retain their own licenses.
